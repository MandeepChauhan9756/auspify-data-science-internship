# Task 2 - Exploratory Data Analysis

## About the Project

In this task, I performed Exploratory Data Analysis (EDA) on a Netflix movies and TV shows dataset.

The main purpose was to understand the data and find useful patterns using Python, Pandas, Matplotlib, and Seaborn.

## Dataset

The dataset contains information about Netflix movies and TV shows.

After the data cleaning and preprocessing from Task 1, the dataset contains:

* 8,790 rows
* 16 columns
* 0 missing values
* 0 duplicate rows

## Analysis Performed

### 1. Movies vs TV Shows

I compared the number of Movies and TV Shows available in the dataset.

### 2. Titles Added by Year

I analyzed how many titles were added in each year and looked at the overall trend.

### 3. Top Countries

I found the countries that are associated with the highest number of titles in the dataset.

### 4. Top Genres

I analyzed the most common primary genres.

Dramas and Comedies were among the most common genres.

### 5. Content Ratings

I checked the distribution of different content ratings.

TV-MA was the most common rating in the dataset.

### 6. Movie Duration

I analyzed the duration of movies and looked at the overall distribution in minutes.

Most movies were concentrated around the 80–120 minute range.

### 7. TV Show Seasons

I analyzed the number of seasons for TV Shows.

Most TV Shows in the dataset have 1 season.

### 8. Movies vs TV Shows by Year

I compared Movies and TV Shows added during different years.

### 9. Monthly Additions

I analyzed the number of titles added in each month.

July had the highest number of recorded additions, while February had the lowest.
